# Hello World em Go

Este projeto é um exemplo básico de um programa escrito em [Golang](https://go.dev/) com foco em iniciantes. Ele imprime "Olá, mundo em Go!" no terminal.

## 🚀 Requisitos

- Go 1.22+ instalado
- Git

## 🧪 Como executar

Clone o repositório e execute o programa:

```bash
git clone git@github.com-opsxandao:OpsXandao/hello-world.git
cd hello-world
go run main.go
